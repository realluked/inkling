# Inkling

Duolingo-style revision for **Cambridge IGCSE First Language English (0500)**.

- Bite-size lessons for every question on Paper 1 (Reading) and Paper 2 (Writing)
- Writing desk: timed exam tasks with mark schemes and model answers
- Ink check: instant feedback on length, sentence variety, weak words, slang, spelling traps and copied phrases
- Word Hoard: 60+ ambitious words with spaced repetition, plus Word Sprint and Device Dash rounds
- Exam countdown, a daily revision plan, notes, a cheat sheet and an XP league

All reading passages and model answers are original. Not affiliated with Cambridge International.
